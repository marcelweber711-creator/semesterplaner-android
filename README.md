# Semesterplaner – Android-App

Hier liegen **nur die fertigen Android-Versionen** (APK) des Semesterplaners. Der Quellcode ist privat.

## Installieren und aktuell halten

1. [Obtainium](https://github.com/ImranR98/Obtainium) installieren (Open Source, holt Updates direkt von GitHub).
2. In Obtainium **App hinzufügen** und diese Adresse einfügen:
   `https://github.com/marcelweber711-creator/semesterplaner-android`
3. **Installieren** – Obtainium meldet sich, wenn es eine neue Version gibt.

Die Oberfläche lädt die App vom Server; viele Neuerungen kommen deshalb ohne neue APK an.

## Echtheit prüfen

Alle Versionen sind mit demselben Schlüssel signiert. SHA-256 des Zertifikats:

`BC:F8:AE:CB:43:0B:FC:20:37:3E:34:D2:94:4D:C0:F2:39:D2:4F:FE:BB:5A:B6:50:DF:87:0D:9D:EC:56:93:B6`
